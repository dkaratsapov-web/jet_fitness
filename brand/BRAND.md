## Направление
- **Настроение:** премиум, спортивный; тёмная тема — основная для приложения.
- **Палитра:** премиум-люкс (графит/чёрный + благородный акцент) — направление
  выбирается из мудбордов (золото-шампань / платина / изумруд). _уточняется._
- **Типографика:** геометрический гротеск (жирный для «JET», обычный для «FITNESS»).
- **Тон:** мотивирующий-экспертный, **обращение на «ты»**.

Полный брендбук (палитра-токены, типографика, компоненты, правила) собирается
после утверждения логотипа-пакета.
