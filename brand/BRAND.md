# Jet Fitness — бренд

## Логотип (утверждён)
Композиция: **JET** (сверху, прижат к грифу) → марка «штанга-джет» (блины слева,
гриф, нос-самолёт справа) → **FITNESS** (под грифом). Монохром, чёрный на белом.

- **Финальный (light):** Higgsfield job `fd106c2d-18c1-44e4-be9c-25f1505bd7f6`
  `https://d8j0ntlcm91z4.cloudfront.net/user_3FDW4xDpfIw798Hq1MYcfG8Ze1n/hf_20260713_200324_fd106c2d-18c1-44e4-be9c-25f1505bd7f6.png`
- Промежуточные итерации: `8297b1bb` (база с джет-носом) → `737f5fd3` (Fitness под гриф) → `fd106c2d` (JET прижат к грифу).

> Higgsfield отдаёт растр (2K PNG). Для продакшена логотип воспроизводится
> **чистым SVG** (темизация через `currentColor`, чёткость на любом размере,
> крохотный вес). Растровые версии — референс и для сторов/соцсетей.

Тёмная тема — основная. Акцент используется точечно (кнопки, кольца прогресса,
активные состояния) — премиум держится на золоте как «драгоценном» акценте, а не заливках.
- **Типографика:** геометрический гротеск (жирный для «JET», обычный для «FITNESS»).
- **Тон:** мотивирующий-экспертный, **обращение на «ты»**.

Полный брендбук (палитра-токены, типографика, компоненты, правила) собирается
после утверждения логотипа-пакета.
